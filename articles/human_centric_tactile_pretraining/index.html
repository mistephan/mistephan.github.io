从人类触觉到机器人灵巧操作：TTP 如何用 160 小时数据完成可迁移触觉预训练

2026-07-18触觉表征

论文： Human-Centric Transferable Tactile Pre-Training for Dexterous Robotic Manipulation
作者： Chi Zhang、Penglin Cai、Ziheng Xi、Haoqi Yuan、Hao Luo、Wanpeng Zhang、Sipeng Zheng、Chaoyi Xu、Zongqing Lu
单位： 北京大学（Peking University）、BeingBeyond、清华大学（Tsinghua University）
状态： arXiv:2607.01067 v1

机器人在摄像头里看见一张纸、一片薯片和一个插头，并不等于它知道手上正在发生什么。

纸张有没有形成折痕，薯片是快要滑落还是已经被夹碎，插头是否顶在插座边缘——这些决定动作成败的信息，往往藏在接触力、局部压力分布和材料形变里。视觉可以告诉机器人“物体在哪里”，触觉则更接近回答“物理交互进行到了哪一步”。

TTP 这篇工作的核心判断是：触觉不应该等到机器人后训练时才临时加入，而应该像视觉和语言一样，参与基础策略的预训练。 为解决机器人触觉数据昂贵、传感器形态又高度异构的问题，作者先从人类交互中构建大规模触觉—动作数据，再把人手与机器人映射到统一的动作和触觉空间，最后让模型同时预测未来动作与未来触觉。

这项工作的价值不只在于“多加一个触觉输入”，而在于尝试打通一条完整链路：

人类触觉数据 → 跨形态统一表征 → 触觉动力学预训练 → 机器人少量后训练 → 接触密集任务执行

一、先看研究路线：从统一触觉表征到可迁移的 VLA 预训练

要理解 TTP 的位置，需要先区分触觉迁移研究中的三个问题：不同传感器的数据如何表示，人手与机器人之间如何对齐，以及对齐后的触觉知识如何进入机器人策略。

这条研究路线可以分成四个相互衔接的层级：

  • UniTacHand——统一表征层： 把人手和机器人手的触觉投影到形态一致的 MANO 表面，并用少量配对数据对齐潜空间，解决“不同触觉传感器如何说同一种语言”；
  • TactAlign——跨形态传输层： 用 rectified flow 在无配对触觉数据间建立分布映射，强调少量人类数据和零样本迁移，解决“人类触觉如何映射到机器人触觉”；
  • BeingH-0.5——跨形态动作基础层： 把人类和多种机器人动作组织进统一的语义槽位，为不同身体共享运动知识提供底座；
  • TTP——VLA 策略预训练层： 在统一动作与触觉接口上，用大规模人类数据联合预训练动作生成和未来触觉预测，再通过机器人后训练落到多形态、多任务策略。

因此，TTP 不是一个新的触觉传感器，也不只是一个独立的触觉编码器。它推进的是整条技术路线的层级：从“把人手和机器人触觉对齐”，走向“让触觉知识参与通用机器人策略的预训练”。

有了这张路线图，论文后面的三个问题就更容易理解：预训练数据从哪里来，人类与机器人如何共享动作和触觉空间，以及未来触觉预测是否真的改善了接触操作。

二、160 小时 H-Tac 从哪里来：三类数据源覆盖真实触觉与伪触觉

H-Tac 汇集约 160 小时数据、超过 300 个任务和约 13.5 万个 episode。这个数量显著高于论文图中列出的 VTDexManip、AgiBot World、FreeTacMan 与 OmniViTac。不过，H-Tac 并不是由一种传感器、一个采集系统得到的均质数据集，而是三个来源不同的子集：

子集 规模 触觉/动作标签来源 主要价值
HOI-Tac 约 106 小时、1150 万帧、12.48 万序列 从公开手—物体、手—脸和手—场景数据中，根据 MANO 手网格与物体表面距离生成二值接触，再投影到统一触觉表面 用低成本方式获得最大规模、最多样的接触覆盖
DeskTask-Tac 37.2 小时、约 400 万帧、947 episodes，30 Hz 三台 RealSense、触觉手套；手部状态来自多视角三角化或 AprilTag + 动捕手套 提供真实人类双手桌面操作中的连续触觉与动作
InternData-Tac 17.8 小时、约 190 万帧、9563 episodes，30 Hz 在 Genie1、Lift2、Split ALOHA 数据引擎中记录接触位置、法向、距离和力，并投影到 MANO 表面 补充机器人形态和物理接触信息

这里有一个值得特别注意的细节：HOI-Tac 占据绝大多数序列，但其触觉标签主要由几何距离阈值推导，表达的是“接触发生在哪里”，并不等价于真实压力传感器输出。InternData-Tac 还把接近表面但尚未产生力的区域编码为距离衰减的伪接触信号。换句话说，H-Tac 的优势是规模与覆盖，代价是不同子集之间的触觉真实性、噪声模型和信息密度并不一致。

作者用同一个 351 维表面空间吸收这些异构监督，使这种混合成为可能，但论文目前没有给出按子集拆分的下游消融，因此我们还不知道 106 小时几何伪标签、37.2 小时真实手套数据和 17.8 小时机器人接触数据各自贡献了多少。

三、人手与机器人如何对齐：200 维动作空间与 351-taxel 触觉地图

人手和机器人手最大的障碍不是图像域差异，而是“动作”和“触觉”根本没有天然一一对应关系。

TTP 继承 BeingH-0.5 的统一动作空间，将状态与动作组织进 200 个有语义的槽位：右臂与左臂末端位姿、夹爪开合、灵巧手关节、机械臂关节、移动底盘，以及 MANO 人手的形状和姿态参数。不同形态只激活与自己相关的槽位，缺失维度则被掩码。

触觉侧采用 UniTacHand 的统一表面表示：每只手保留 351 个 taxel，并把人类触觉手套、压阻式灵巧手、3D 触觉指尖乃至视觉触觉夹爪的数据投影到 MANO 手表面。这样，“食指指腹受力”就不再绑定某一款传感器的像素或通道编号，而成为跨形态可复用的空间语义。

这一步是全文最关键的工程选择。没有统一空间，人类预训练与机器人后训练只是两套输入输出接口相近、语义却不连续的任务；有了统一空间，预训练学到的“接触位置—手部运动—物体状态”关系才有机会保留下来。

四、模型如何学习接触动力学：同时预测未来动作与未来触觉

模型基于 BeingH-0.5，包含三个相互协作的专家：

  • 理解专家处理语言和视觉，并接收动作/触觉预测相关上下文；
  • 动作专家通过 flow matching 生成未来动作 chunk；
  • 触觉专家预测未来一段时间的触觉序列。

模型输入不是单帧触觉，而是带时间步长的触觉历史，以保留近期接触变化。训练目标则是动作 flow-matching loss 与触觉 flow-matching loss 的加权和，论文中两者权重都设为 1.0。

为什么“预测未来触觉”比“把当前触觉作为输入”更重要？因为接触控制本质上依赖动力学：

  • 当前压力上升后，继续闭合手指会不会夹碎物体？
  • 插头沿当前方向推进，下一时刻会顺利进入还是产生侧向碰撞？
  • 擦拭时压力和轨迹如何共同决定下一时刻的接触区域？

当模型被要求预测未来触觉，它就不能只把触觉当成附加特征，而必须学习动作与接触变化之间的关系。作者还加入 Tactile-Action Manifold-Preserving Gating（MPG）：用 sliced Wasserstein distance 衡量当前上下文与无噪声动作、触觉锚点之间的分布偏差；上下文越不可靠，残差增强门控越小，以降低分布偏移下的预测方差。

五、TTP 到底提升了什么：仿真守住通用能力，真机改善接触操作

1. 仿真基准并没有出现压倒性提升

LIBERO、LIBERO-plus 和 RoboCasa 原生没有触觉。为了保留双目标训练，作者用“上一时刻动作与当前本体状态之差”补零后作为触觉代理。这能测试加入触觉分支后是否破坏通用 VLA 能力，却不能严格证明真实触觉理解。

TTP 在 LIBERO 平均成功率为 98.1%，BeingH-0.5 为 98.0%；在 RoboCasa 上分别为 55.1% 和 53.9%。真正较明显的差距出现在零样本 LIBERO-plus：TTP 为 75.7%，BeingH-0.5 为 71.7%，其中语言、光照和布局变化表现更好。

因此，更准确的结论是：触觉预训练没有牺牲原有视觉—语言—动作能力，并带来一定的分布外泛化收益，而不是“触觉让所有仿真任务大幅提升”。

2. 真实机器人任务给出了更有说服力的证据

真机实验覆盖 9 个任务、单臂与双臂、6/7 自由度机械臂，以及三类末端执行器：压阻式 Inspire 灵巧手、DM-Tac 视觉触觉夹爪和 DexBotic 3D 触觉手。任务被分为精细操作、接触密集/易碎物体和视觉缺陷三类。

以 TTP 自身表现归一化为 100% 后，跨 ID 与 OOD 测试的平均任务进度为：

  • 精细操作：TTP 为 96.7%，无预训练 TTP 为 71.0%，BeingH-0.5 为 57.3%；
  • 接触密集与易碎物体：TTP 为 79.2%，无预训练 TTP 为 49.7%，BeingH-0.5 为 9.2%；
  • 视觉缺陷：TTP 为 37.8%，无预训练 TTP 为 26.7%，BeingH-0.5 为 15.6%。

原始任务指标更直观：

  • Inspire 手削萝卜皮，ID 平均长度从无预训练版本的 14.65 cm 提升到 23.33 cm；OOD 从 11.25 cm 提升到 19.12 cm；
  • 双臂折纸，ID 指标从 57% 提升到 84%，OOD 从 24% 提升到 87%；
  • 完整夹取并放置薯片，ID 成功率从 60% 提升到 80%，OOD 从 40% 提升到 60%；
  • 但插接仍然困难：两个插接任务的成功率大多只有 10%–20%，说明触觉预训练并没有解决高精度装配中的全部问题。

六、哪些设计真正有效：未来触觉预测、MPG 与数据规模消融

在固定 15 万步预训练下，完整 TTP 的 MPJPE 为 23.5711；去掉未来触觉预测后为 24.5518，去掉 MPG 后为 24.7597，两者都去掉时升至 25.5850。数据规模从 10% 增至 100% 时，MPJPE 从 33.1917 单调下降至 23.5711，四项运动预测误差均持续改善。

这些结果支持两个判断：未来触觉预测和 MPG 对人手运动预测都有帮助，且预训练仍处于明显的数据扩展区间。

但它们还不能完全回答更重要的问题：

  1. 消融只报告预训练验证集上的运动误差，没有把“去掉触觉专家”或“去掉 MPG”一路评估到 9 个真机任务；
  2. 论文没有单独消融 200 维统一动作空间与 351-taxel 统一触觉空间；
  3. 没有比较不同 H-Tac 子集、真实触觉与几何伪触觉各自的下游贡献；
  4. 没有报告同一设置多次训练的方差，因此单调扩展曲线的稳定性仍需更多证据。

结语

TTP 展示了一种很有潜力的范式：机器人不必只靠自己昂贵地试错，才能学会力道、滑移和接触节奏；人类长期积累的触觉交互，可以先被编码为跨形态的共同语言，再转移到不同机器人身体上。

不过，“共同语言”并不意味着形态差异已经消失。MANO 表面投影会压缩传感器特有信息，几何伪接触与真实压力也不是同一种信号，低次数真机测试更不足以证明普适可靠性。TTP 更像是把一条以前断裂的道路接通了：从人类触觉到机器人策略，现在已经可以通行；至于这条路能承载多大的数据规模、多少种传感器和多复杂的装配任务，仍需要后续工作继续铺设。
